# RV32I Single-Cycle CPU

This directory contains the Logisim-evolution implementation of an RV32I single-cycle RISC-V processor.

## Current Progress

- [x] 4-bit Register
- [x] 32-bit Register
- [x] 5-to-32 Decoder
- [x] Register File
- [ ] ALU
- [ ] Control Unit
- [ ] Instruction Memory
- [ ] Data Memory
- [ ] Program Counter
- [ ] Complete Single-Cycle CPU

## Tools

- Logisim-evolution
- RISC-V RV32I ISA

## Project Goal

The goal is to build an RV32I RISC-V processor from scratch, starting with the register subsystem and progressively integrating the datapath and control logic.

The completed single-cycle processor will serve as the foundation for a future pipelined RISC-V implementation.
